SEO-версия сайта mcdimix.ru

Файлы архива:
- index.html — главная страница
- santehnik-perm.html — страница сантехнических услуг
- elektrik-perm.html — страница бытовых электротехнических услуг
- sborka-mebeli-perm.html — страница сборки мебели
- style.css — оформление
- robots.txt — правила обхода сайта
- sitemap.xml — карта сайта

Публикация на GitHub Pages:
1. Распакуйте архив.
2. Откройте репозиторий https://github.com/Mcdimix/master-perm
3. Загрузите файлы из этой папки в корень репозитория. Не загружайте саму папку как вложенную папку.
4. Подтвердите замену index.html, если GitHub предложит её.
5. Дождитесь обновления GitHub Pages.
6. Проверьте адреса:
   https://mcdimix.ru/
   https://mcdimix.ru/santehnik-perm.html
   https://mcdimix.ru/elektrik-perm.html
   https://mcdimix.ru/sborka-mebeli-perm.html
   https://mcdimix.ru/sitemap.xml
7. Отправьте sitemap.xml в Google Search Console и Яндекс Вебмастере.

Перед публикацией проверьте телефон, услуги и формулировки. Не добавляйте выдуманные отзывы, рейтинги, опыт или гарантии. Фото работ можно добавить позднее, сохранив их в репозитории и подключив к страницам.
